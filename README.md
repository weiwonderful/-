# 🐍 贪吃蛇小游戏 (Snake Game)

一个使用纯 HTML + CSS + JavaScript 实现的贪吃蛇小游戏，无需任何依赖，打开即玩。

## ✨ 功能特性

- 🎮 **键盘控制**：方向键或 WASD 控制蛇的移动方向
- ⏸️ **暂停功能**：按空格键暂停/继续游戏
- 📱 **移动端支持**：手机端提供虚拟方向键
- 🏆 **最高分记录**：使用 localStorage 保存历史最高分
- ⚡ **难度递增**：每得 50 分自动加速，挑战你的反应极限
- 🎨 **霓虹风格 UI**：渐变背景、发光蛇身、粒子食物效果
- 🔄 **即时重开**：游戏结束后一键再来一局

## 🚀 如何运行

直接用浏览器打开 `index.html` 即可开始游戏，无需安装任何东西。

```bash
# 或者用本地服务器运行
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎯 游戏规则

1. 控制蛇吃掉红色食物，每吃一个得 **10 分**
2. 蛇身会随着吃食物而变长
3. 撞到墙壁或自己的身体则游戏结束
4. 每得 50 分速度提升一档，最高 10 档
5. 不能直接反向移动（会撞到自己）

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` | 控制方向 |
| `W` `A` `S` `D` | 控制方向 |
| `空格` | 暂停 / 继续 |
